DIGITAL LIBRARY

Greetings!

This project aims to help provide a relational dbms solution to track book loans and generate relevant
data to run necessary library operations.

Features:

* Tables for different entities such as books, students, issued books.
* Help find defaulter students who havent returned books.
* Find which books are borrowed most.
* Delete student records for those who havent borrowed in more than 3 years.

Created an sql file with all necessary commands.
Some parts have been commented out as they were redundant after populating database.
